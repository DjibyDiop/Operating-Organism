# oo-desktop

Petit scaffold pour le composant "oo-desktop" du projet OO.

But
- Fournir un point d'entrée simple pour lancer l'environnement "desktop" local.

Usage
- PowerShell: `.\
un\launch.ps1` depuis le dossier `oo-desktop`.
- CMD: `launch.bat`.

Prochaines étapes
- Implémenter une interface graphique (Electron / PyQt / Tauri) si souhaité.
